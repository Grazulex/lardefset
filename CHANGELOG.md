## [v0.1.0] - 2026-11-09

### Added

- First release: ten configurables applied on boot (`AggressivePrefetching`, `AutomaticallyEagerLoadRelationships`, `FakeSleep`, `ForceScheme`, `ImmutableDates`, `PreventStrayRequests`, `ProhibitDestructiveCommands`, `SetDefaultPassword`, `ShouldBeStrict`, `Unguard`), each toggled from `config/lardefset.php`.
- Supports PHP 8.4+ and Laravel 12.8+ / 13.
